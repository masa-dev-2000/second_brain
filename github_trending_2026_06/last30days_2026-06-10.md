# AI coding tools Claude Code Cursor Copilot

🌐 last30days v1.0 · synced 2026-06-10

What I learned:

2026年前半、AIコーディングツール市場は「3強時代」の最終確立期に入った。Stack Overflow Developer Surveyによれば、[GitHub Copilot](https://pasqualepillitteri.it/en/news/3392/github-copilot-cursor-claude-code-ai-coding-showdown-2026)の職業開発者シェアは67%から51%に下落し、[Cursor](https://www.nxcode.io/resources/news/cursor-vs-claude-code-vs-github-copilot-2026-ultimate-comparison)が18%、[Claude Code](https://www.cosmicjs.com/blog/claude-code-vs-github-copilot-vs-cursor-which-ai-coding-agent-should-you-use-2026)が初登場10%を記録した。Cursorはすでに年間ARR 20億ドル・ユーザー100万人超という商業的快走を続けており、[JetBrainsの調査](https://www.sitepoint.com/claude-code-vs-cursor-vs-copilot-the-2026-developer-comparison/)では経験10年超の開発者の46%が「毎日使うなら」Claude Codeを選ぶと回答 - Copilotを選んだのはわずか9%だった。

Hacker Newsでは「[Cursor 3のリリーススレッド](https://news.ycombinator.com/item?id=47618084)」と「[Claude CodeをCursor IDE内で使っている話](https://news.ycombinator.com/item?id=47619752)」がほぼ同時に盛り上がり、実務家の間では「Cursorで書いてClaude Codeで直す」という2ツール並用が標準になりつつある。あるHNユーザーは「[Cursorを2024年11月から2026年2月まで使い、今はClaude Code+VSCodeに移行した](https://news.ycombinator.com/item?id=44471007)」と書き、Claude Codeの1Mコンテキストウィンドウ(Copilotの200Kと比較)が大規模リファクタリングで決定的だと指摘した。一方で6月1日にCopilotがリクエスト課金からAI Credits消費型へ[課金体系を変更](https://www.developersdigest.tech/blog/ai-coding-tools-pricing-2026)したことで、ヘビーユーザーのコストが予測困難になる懸念も浮上している。

6月時点で最も注目されたニュースは2つある。まず[Microsoftが同社Experiences+Devices部門向けのClaude Codeライセンスを6月30日付でキャンセル](https://spacedaily.com/n-microsoft-is-canceling-claude-code-licenses-across-its-experiences-devices-division-by-june-30-steering-thousands-of-engineers-toward-github-copilot-while-uber-burned-through-its-entire-2026-ai-bu/)し、GitHub Copilotへ誘導すると発表 - 親会社がGitHub(Copilot)を持つ以上、当然の判断とも言える。次にUberのCTOが「2026年通年のAIコーディング予算を4月時点で使い切った」と認め、Claude CodeとCursorの組み合わせが想定外のコストを生んだことを明かした。また5月28日には[Claude Opus 4.8がリリース](https://thenewstack.io/ai-coding-tool-stack/)され、SWE-Bench Verifiedで88.6%を達成 - これはClaude Codeユーザーが直接享受する性能向上だ。さらにWindsurfが[Devin Desktopへリブランド](https://lushbinary.com/blog/ai-coding-agents-comparison-cursor-windsurf-claude-copilot-kiro-2026/)した6月2日、第4のプレイヤーも存在感を示し始めている。

KEY PATTERNS:
- **2ツール併用が標準化** - [Cursor(日常編集)+Claude Code(重作業)](https://hashnode.com/forums/thread/claude-code-vs-cursor-vs-copilot-a-brutal-2026-review)という分業スタックが経験豊富な開発者の間で定着し、平均使用ツール数は2.3本
- **Copilotのエンタープライズ防衛戦** - Microsoftが社内でClaude Codeを排除し始めるなど、[Copilotはエンタープライズ契約・SSO・監査ログで差別化](https://www.cosmicjs.com/blog/claude-code-vs-github-copilot-vs-cursor-which-ai-coding-agent-should-you-use-2026)する戦略にシフト
- **Claude CodeのコンテキストADVが拡大** - 1Mトークン文脈 vs Copilotの200K制限という[技術格差](https://news.ycombinator.com/item?id=46570115)が、大規模コードベース案件での選定基準になっている
- **コスト爆発リスクが顕在化** - UberのAI予算枯渇事例と[Copilotの従量課金移行](https://spectrumailab.com/blog/ai-coding-tools-pricing-compared-2026)が重なり、企業レベルの予算管理が2026年後半の最重要テーマに
- **Cursor 3 + Claude Code統合が次の焦点** - [Cursor IDEのエクステンション経由でClaude Codeを動かす](https://news.ycombinator.com/item?id=47619752)使い方が広まり、ツール境界が溶け始めている
