## ストーリーの読み方

各ストーリーは以下の構成で書かれている：

1. **登場人物** — 主人公のプロフィール
2. **問題** — 具体的な課題（数字を含む）
3. **出会い** — Claude Code との接点
4. **実装** — 実際の操作・コマンド・プロンプト例
5. **壁** — 必ず直面したつまずき
6. **解決** — 乗り越え方
7. **結果** — Before/After の数字比較
8. **使った機能** — 活用した Claude Code の機能一覧
