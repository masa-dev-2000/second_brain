# Dify — 10のストーリー

## Dify とは

ノーコード〜ローコードで LLM アプリ・RAG・エージェントを構築する OSS プラットフォーム。
ビジュアル DAG ワークフロービルダーにより、LLM / RAG / HTTP Request / Code / Human Input など
多様なノードをドラッグ＆ドロップで接続し、本番稼働レベルの AI アプリを素早く構築できる。

**主な機能**
- Chatbot / Workflow / Agent / Chatflow アプリの作成
- ビジュアル DAG ワークフロービルダー
- Knowledge Base（RAG・ハイブリッド検索）
- MCP 双方向対応
- 100+ モデル対応（GPT-4o・Claude・Gemini 他）
- Scheduled / Webhook / Plugin トリガー
- 1.4M+ デプロイ実績、175+ カ国で利用
