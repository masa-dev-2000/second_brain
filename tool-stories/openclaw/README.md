## OpenClaw とは

OpenClaw は「自分のデバイスで動かす、自律型パーソナルAIアシスタント」です。  
質問に答えるだけのチャットボットとは異なり、**行動する・スケジュールで動く・記憶する**という3つの特性を持ちます。

### 主な機能

- **マルチチャンネル対応**：WhatsApp / Telegram / Slack / Discord / iMessage / LINE など20種類以上のチャンネルに接続
- **ブラウザ操作**：Webサイトの閲覧・フォーム入力・データ抽出を自律実行
- **ファイル・シェル操作**：ファイル読み書き・シェルコマンド・スクリプト実行
- **永続メモリ**：MarkdownファイルとSQLiteでセッションをまたいで記憶を保持
- **スケジューリング**：cronベースで定期的にタスクを自律実行
- **音声対応**：macOS/iOS でウェイクワード、Android で常時音声認識
- **Canvas（ビジュアルワークスペース）**：エージェント駆動のライブUI

### アーキテクチャ概要

```
[チャンネルゲートウェイ]
    ↓ ルーティング
[エージェントオーケストレーター]
    ↓ コンテキスト組み立て（記憶・履歴・指示）
[LLM推論 + ReActループ]
    ↓ ツール呼び出し
[ツール層：ブラウザ / ファイル / シェル / API]
    ↓ 結果統合
[メモリ更新 → 次回セッションへ]
```

### セットアップ例

```bash
npm install -g openclaw@latest
openclaw onboard --install-daemon
```

`SOUL.md`（AIの人格定義）と `USER.md`（ユーザー情報）を設定することで、  
自分専用にカスタマイズされたアシスタントが起動します。
