# ストーリー10：「研究論文の海を泳ぐ」
副題 ── 高橋 菜々子、1,200本の論文を3日で読破した話 ──

## 登場人物
高橋 菜々子（たかはし ななこ）・25歳・国立大学医学系大学院の修士2年生。  
専門はAIを用いた医療画像診断。修士論文の執筆に向けた文献レビューで行き詰まっていた。  
指導教員から「関連する先行研究を網羅してから書け」と言われているが、  
関連論文がPubMedだけで1,200件以上ヒットしており、全部読む時間がなかった。

## 問題
論文1本を精読するのに平均40〜60分かかる。  
1,200本を全部読むと800〜1,000時間必要で、修士論文の締め切りまでに物理的に不可能だった。  
「どの論文が本当に重要か」を判断するためにはまず読まないといけない、という矛盾があった。  
重要論文を見落として指導教員に指摘されるのが最も恐れていた事態だった。

## 出会い
同じ研究室の先輩が「OpenClaw に論文の要約をやらせている」と話していた。  
「AIに論文を読ませていいのか、最初はためらった」と菜々子は言う。

## 実装
```bash
openclaw onboard
# ファイルシステム + ブラウザ + Notionデータベース統合
```

```markdown
# SOUL.md（文献レビューエージェント）
あなたは医学系研究の文献レビューアシスタントです。

各論文PDFを読み込み、以下を抽出してNotionデータベースに登録してください：
- タイトル・著者・発行年・ジャーナル名・被引用数
- 研究目的（1文）
- 手法（2〜3文）
- 主要結果（数値を含む2〜3文）
- 本研究との関連性スコア（1〜5）
- 関連性の理由（1文）

高橋の研究テーマ：「深層学習を用いたCT画像からの早期肺がん検出精度の向上」
関連性スコア4以上の論文は「重要文献」フラグを付けてください。
```

## 壁
英語論文の医学専門用語と統計手法の説明が複雑で、  
OpenClaw が「主要結果」を正確に要約できず、数値を誤って転記するケースが約15%あった。  
特に「p値」「感度・特異度」「AUC」などの値が混在する表の読み取りが不正確だった。

## 解決
「数値が含まれる文章はそのまま原文を引用する」「要約ではなく原文抜粋にする」  
というルールを `SOUL.md` に追加した。  
数値の正確性より原文引用を優先することで、菜々子が確認する際のリスクを下げた。  
「正確さと速さのトレードオフを、自分で判断して設計できた」と菜々子は話す。

## 結果

| 指標 | Before（想定） | After |
|------|----------------|-------|
| 1,200本の初期スクリーニング時間 | 約200時間 | 3日間（自動処理） |
| 精読すべき「重要文献」に絞り込み | ─ | 87本（全体の7.2%） |
| 87本の精読にかかる実際の時間 | ─ | 約70時間（現実的な範囲） |
| 指導教員への中間報告の質 | 「まだ読めていません」 | 「87本を精読済み・分類完了」 |

「先生に報告したら『君は早いね』と言われた。全部は話せなかった」

## 使った機能

| 機能 | 用途 |
|------|------|
| ファイルシステム統合 | PDFの一括読み込みと解析 |
| Notion統合 | 文献データベースの自動構築 |
| ブラウザ操作 | PubMedからのPDF取得 |
| 永続メモリ | 関連性判断の基準維持 |
| SOUL.md 研究コンテキスト | 研究テーマと重要度スコア基準の定義 |
