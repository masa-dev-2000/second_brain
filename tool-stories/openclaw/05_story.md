# ストーリー5：「車の値引き交渉AI」
副題 ── 西村 明、AIに交渉させて42万円を引き出した話 ──

## 登場人物
西村 明（にしむら あきら）・45歳・大手メーカーの営業部長。  
交渉のプロを自認しているが、車の購入交渉だけは「面倒くさい」と後回しにしがちだった。  
新型SUVへの買い替えを検討し始めて半年、まだ1件も見積もりを取っていなかった。

## 問題
希望する車種を扱うディーラーが関東圏に23店舗あったが、  
1件ずつ連絡するのが億劫で放置していた。  
「相見積もりを取れば安くなる」とわかっているが、  
23件に個別対応する時間も気力もなかった。

## 出会い
「OpenClaw でディーラー交渉を全部やらせた」という記事を読んで衝撃を受けた。  
「そんなことができるのか、と思いながら読んでいたら記事の最後に$4,200節約できたって書いてあって、試すしかないと思った」

## 実装
```bash
openclaw onboard
# ブラウザ + メール + LINE統合
```

```markdown
# SOUL.md
あなたは車の購入交渉を担当するアシスタントです。

目標：西村氏が希望するSUV（車種名・グレード・色を指定）を
最安値で購入する見積もりを獲得する。

手順：
1. 関東圏の該当ディーラー23店舗のWebフォームから見積もりを申込む
2. 返信メールを集計して最安値上位5店舗をリストアップ
3. 各店舗に「他店より5万円以上安くなれば即決する」旨を伝えるメールを送る
4. 最終見積もりを比較して推奨店舗を1件提示する
```

## 壁
一部ディーラーのWebフォームが、ロボット対策のCAPTCHAを採用しており、  
OpenClaw のブラウザ操作がブロックされ、8店舗への申し込みが失敗した。

## 解決
失敗した8店舗は、OpenClaw が自動生成した問い合わせメール文をコピーして  
明がGmailから手動送信する方式に切り替えた。  
「全自動にこだわらなくていいんだ、という気づきだった」と明は言う。  
合計15店舗から見積もりが集まり、十分な相見積もりが成立した。

## 結果

| 指標 | Before（想定） | After |
|------|----------------|-------|
| 見積もり取得件数 | 0件 | 15件 |
| 交渉にかけた自分の時間 | ─ | 約40分（メール転送のみ） |
| 最初の見積もりとの差額 | ─ | 420,000円値引き達成 |
| 購入決定までの期間 | 6ヶ月（放置） | 10日 |

「ディーラーの担当者から『熱心なお客様ですね』と言われた。全部AIだとは言えなかった」

## 使った機能

| 機能 | 用途 |
|------|------|
| ブラウザ操作 | ディーラーWebフォームへの申し込み |
| メール統合 | 見積もり返信の収集・交渉メール送信 |
| データ集計 | 複数見積もりの比較表生成 |
| SOUL.md 交渉戦略 | 交渉手順と目標価格の定義 |
