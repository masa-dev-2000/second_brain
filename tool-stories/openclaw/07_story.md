# ストーリー7：「CRM自作の週末」
副題 ── 小林 美咲、6,000ドルのSaaSをゼロコストに置き換えた話 ──

## 登場人物
小林 美咲（こばやし みさき）・32歳・ベンチャーキャピタルのアナリスト。  
20社のポートフォリオ企業の進捗管理を担当している。  
ツールの維持費が問題視され始めており、上司から「コスト削減の提案をしてほしい」と言われていた。

## 問題
CRMとして Affinity に月50万円（年600万円）、進捗管理に Monday.com に月12万円を支払っていた。  
しかしチームが実際に使う機能は全体の20%以下。  
「高機能すぎて使いこなせていない」という状態が2年続いていた。

## 出会い
海外のVCブログで「OpenClaw でCRMを自作した」という記事を見つけた。  
「週末2日でできる、と書いてあった。それなら失敗してもいいと思って試した」

## 実装
```bash
openclaw onboard
# Gmail + Notion + Google Calendar 統合
```

```markdown
# SOUL.md（CRMエージェント定義）
あなたはVCのポートフォリオCRMアシスタントです。

管理対象：20社のポートフォリオ企業
記録する情報：
- 最終コンタクト日・次回予定日
- 最新の月次KPI（MRR/ARR/採用状況）
- 重要な課題と次のアクション
- 過去のメモと意思決定履歴

毎週月曜朝にポートフォリオサマリーをSlackに送信してください。
創業者からのメールを受信したら自動的にNotion DBを更新してください。
```

土曜日の午後にセットアップし、日曜の夜には最初のサマリーが届いた。

## 壁
Notion の APIレート制限に引っかかり、20社分のデータを一括更新しようとすると  
途中でエラーになって処理が止まってしまった。  
最初の週は毎回手動でリトライが必要な状況が続いた。

## 解決
一括更新を廃止し、1社ずつ5分間隔で更新するバッチ処理に変更した。  
OpenClaw の cron で「1時間に12社ずつ処理する」スケジュールを組み直すことで  
APIレート制限に引っかからなくなった。

## 結果

| 指標 | Before | After |
|------|--------|-------|
| CRM関連ツール費用 | 月62万円 | 月0円（OpenClaw本体のみ） |
| 年間削減額 | ─ | 744万円 |
| 週次レポート作成時間 | 2時間 | 0分（自動生成） |
| 情報更新の遅延 | 平均3〜5日 | リアルタイム（メール受信時） |

「上司に削減額を報告したら、2秒くらい黙ってから『本当に？』と聞かれた」

## 使った機能

| 機能 | 用途 |
|------|------|
| Gmail統合 | 創業者メールの自動取り込み |
| Notion統合 | ポートフォリオDBの自動更新 |
| Google Calendar統合 | 面談スケジュールの同期 |
| cronスケジューリング | 週次サマリーの自動生成 |
| 永続メモリ | 各社のコンテキスト維持 |
