# ストーリー6：「在宅父の育児ログ」
副題 ── 松本 雄介、子どもの成長記録を自動化した話 ──

## 登場人物
松本 雄介（まつもと ゆうすけ）・35歳・フリーランスのWebデザイナー。  
妻が職場復帰したため、1歳半の娘・さくらの保育園送迎と昼間の育児を担当している。  
クライアントの締め切りと育児の両立で、「自分の時間」がほぼゼロの状態が続いていた。

## 問題
小児科の先生から「成長の記録を続けてほしい」と言われているが、  
育児アプリへの入力が後回しになり、気づくと2〜3日分の記録が空白になっていた。  
また、保育園からの連絡帳に「家での様子」を毎日書く必要があったが、  
「何か特別なことを書かなければ」というプレッシャーで毎晩10分費やしていた。

## 出会い
育児コミュニティのSlackで「OpenClaw を子育て記録に使っている」という投稿を見た。  
「音声で話しかけるだけでログが取れるって書いてあって、試してみた」

## 実装
```bash
openclaw onboard
# 音声入力（Android端末）+ LINEチャンネル設定
```

```markdown
# SOUL.md
あなたはさくら（1歳半・女の子）の育児ログを管理するアシスタントです。

受け取った内容を以下の形式で記録してください：
- 日時・体温・食事内容・睡眠時間・特記事項
- 毎週日曜夜に「週間サマリー」をLINEで送る
- 連絡帳の「家での様子」欄に使える3行の文章を毎晩20時に提案する
```

音声で「今日のお昼はうどん半分食べた、昼寝は13時から2時間」と話しかけるだけで記録される。

## 壁
娘がぐずって泣いている最中に音声入力しようとすると、  
OpenClaw が泣き声を「ユーザーの発言」として誤認識し、意味不明なログが記録されてしまった。  
泣き声の中での入力精度が著しく低かった。

## 解決
ウェイクワードを特定の言葉（「ログ開始」）に設定し、  
ウェイクワードの後5秒以内に録音が始まる方式に変更した。  
さらに「確認してよければ『OK』と言う」という2段階確認フローを追加したことで、  
誤記録がほぼなくなった。

## 結果

| 指標 | Before | After |
|------|--------|-------|
| 育児ログの空白日数 | 週に2〜3日 | ほぼゼロ |
| 連絡帳記入時間 | 毎晩10分 | 毎晩1分（提案を確認するだけ） |
| 小児科への記録持参 | ほぼ持参できず | 毎回グラフ付きで持参可能 |
| 記録の継続率 | 約60% | 約95% |

「『今日のさくら』ってLINEが毎週来るのが楽しみになった。自分が育児している実感が持てるようになった」

## 使った機能

| 機能 | 用途 |
|------|------|
| 音声入力（Android） | ハンズフリーでの育児ログ入力 |
| LINE統合 | 週間サマリーの受信 |
| 永続メモリ（SQLite） | 継続的な成長記録の管理 |
| cronスケジューリング | 毎晩20時の連絡帳文案提案 |
| SOUL.md 記録フォーマット | ログの構造化ルール定義 |
