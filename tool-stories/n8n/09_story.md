# ストーリー9：「データを血液のように」
副題 ── 加藤翔太と、CSV・DB・BIの三点繋ぎ ──

## 登場人物
加藤 翔太（かとう しょうた）、36歳。物流系企業のデータアナリスト。  
基幹システム（オンプレ・Oracle DB）からCSVを手動エクスポートし、PostgreSQLに加工して投入、最終的にTableauでダッシュボードを更新する業務が日課。  
「データパイプラインが壊れてもアナリストが知るのは上長からのクレームが来てから」という状態に疲弊していた。

## 問題
毎朝7:30に出社してCSVエクスポート → 変換スクリプト実行 → PostgreSQL投入 → Tableau更新確認という一連の作業に毎日1時間30分かかっていた。  
月に2〜3回、変換スクリプトがエラーで止まり、気づかずにTableauに古いデータが表示され続ける事故が発生。経営会議に古いKPIが提示されたことも過去に2回あった。  
Oracle DBへのアクセスはVPN必須で、リモートワーク日は作業のために出社を余儀なくされていた。

## 出会い
社内の情報システム部門の勉強会でn8nが紹介された。「Oracleにも繋がるし、サーバサイドで動かせる」という説明に翔太は飛びついた。会社のオンプレサーバにDockerでn8nを立てる許可をIT部門から取得し、構築を開始した。

## 実装
```
【毎朝のデータパイプライン】
[Schedule Trigger] 毎日6:00 AM
    ↓
[Oracle DB] 昨日分の出荷・在庫・配送データを SELECT
    ↓
[Code（JavaScript）] データのクレンジング処理：
    - 日付フォーマットの統一（YYYYMMDD → ISO8601）
    - NULL値の補完
    - 重複レコードの除去
    ↓
[PostgreSQL] staging テーブルに TRUNCATE → INSERT
    ↓
[HTTP Request] dbt Cloud API で変換ジョブをトリガー
    ↓
[Wait] dbt ジョブ完了まで最大10分ポーリング
    ↓
[HTTP Request] Tableau REST API で
データソースを「最新の情報に更新」
    ↓
[IF] Tableau更新が成功したか？
    ↓ YES                ↓ NO
[Slack]              [Slack #data-alert]
#data-statusに        エラー詳細を投稿
「更新完了」を投稿      + 加藤にDM通知

【データ品質チェックフロー】
[Schedule Trigger] パイプライン完了後 10分後
    ↓
[PostgreSQL] 本日のレコード件数・NULL率・
範囲外値の件数をクエリ
    ↓
[IF] 品質スコア < 閾値（95%）?
    ↓
[Slack] データ品質アラート＋詳細レポートを投稿
```

## 壁
dbt CloudのAPIジョブ完了をポーリングする実装で、ジョブが10分以上かかったケースに対応できず、n8nのワークフロー自体がタイムアウトしてしまう問題が発生した（月2〜3回）。

## 解決
ポーリングループに最大試行回数（30回・20秒ごと = 最大10分）の上限を設け、超過した場合はn8nのワークフロー自体は「処理中」としてSlack通知し、別の「dbt完了確認ワークフロー」をWebhookで呼び出す非同期アーキテクチャに再設計した。dbt Cloud側のJobの完了通知Webhookをn8nのエンドポイントに向けることで根本的に解決した。

## 結果
| 指標 | Before | After |
|------|--------|-------|
| 毎朝の手動作業時間 | 1時間30分 | 0分（完全自動） |
| データ遅延事故（月） | 2〜3件 | 0件（異常は即Slackアラート） |
| リモートワーク出社義務 | 週1〜2回 | 不要 |
| パイプライン監視 | 人力（気づけば） | 自動品質チェック |

## 使ったn8nノード・機能
| ノード/機能 | 用途 |
|-----------|------|
| Schedule Trigger | 毎朝6:00の定時起動 |
| Oracle DB | 基幹システムからのデータ取得 |
| Code（JavaScript） | データクレンジング・変換処理 |
| PostgreSQL | ステージングDBへの書き込み |
| HTTP Request（dbt Cloud API） | 変換ジョブの起動・完了確認 |
| HTTP Request（Tableau API） | ダッシュボードの更新トリガー |
| Wait | ジョブ完了待機のポーリング |
| IF | 成否判定・品質スコア閾値判定 |
| Webhook Trigger | dbt完了通知の非同期受信 |
| Slack | 完了通知・アラート・DM |
