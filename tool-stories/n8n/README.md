# n8n — 10のストーリー

## n8n とは

ノーコード〜ローコードのワークフロー自動化ツール。  
セルフホスト可能（Dockerで簡単起動）、400+インテグレーション対応、AI（LangChain/GPT/Claude）ネイティブ対応。  
Zapierと異なりタスク数無制限プランがあり、技術者がいるチームにとってコストメリットが大きい。
