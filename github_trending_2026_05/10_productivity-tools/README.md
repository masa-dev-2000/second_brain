# 10_productivity-tools

## フォルダの概要

個人・チームの生産性向上に貢献するオープンソースツールをまとめたカテゴリ。プライバシーファーストのAI議事録ツールMeetily、オープンソースNotion代替のAppFlowy、Confluenceに代わるWikiツールDocmost、そしてサブスクリプション費用を可視化するWallosを収録している。SaaSサービスへの依存とプライバシーリスクへの懸念から、セルフホスト可能なオープンソースの生産性ツールへのシフトが加速しており、コスト削減・データ自己管理の観点から個人・企業の両方で採用が増えている。

## カテゴリの傾向

- **脱SaaSとセルフホストの潮流**: Notion・Confluence・OtterAIなどの商用SaaSに対して、セルフホスト可能なOSS代替が急増している。月額費用の削減に加えて、GDPR・個人情報保護法対応・社内情報セキュリティポリシーへの対応という観点から、データを自社インフラで管理したいという需要が強まっている。
- **AIとの深い統合**: 従来の「ツール」がAI機能を標準搭載するようになっている。AppFlowyのAIアシスタント・MeetilyのローカルWhisper/Ollama連携のように、クラウドAPIに依存せずローカルのAIモデルと統合することで、プライバシーを保ちながらAIの恩恵を受けられる設計が評価されている。
- **サブスクリプション疲れの顕在化**: SaaS時代の副産物として「知らない間に課金が積み重なっている」問題が広く認識されるようになり、Wallosのようなサブスク管理ツールが需要を集めている。個人・家族・スタートアップの財務健全化ツールとしてセルフホスト型の家計管理OSSが台頭している。
