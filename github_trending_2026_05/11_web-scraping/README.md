# 11_web-scraping

## フォルダの概要

Webスクレイピングとブラウザ自動化に特化したオープンソースライブラリをまとめたカテゴリ。Apifyが開発するCrawlee（Node.js版・Python版）を収録しており、AI・LLM・RAGシステム構築のためのWebデータ収集パイプラインに特化した設計が特徴となっている。プロキシローテーション・リクエストキュー・自動リトライなどのスクレイピングにおける「定型の面倒ごと」を標準搭載することで、データエンジニアやMLエンジニアがデータ収集ロジックよりもデータ活用に集中できる環境を提供する。

## カテゴリの傾向

- **AIデータパイプラインとしての再定義**: 従来のWebスクレイピングツールが「LLM/RAGのためのデータ収集インフラ」として再定義されつつある。CrawleeはLLM用の clean text 抽出・ベクトルDBへの直接受け渡しを意識した設計となっており、スクレイピング→前処理→インジェストのパイプラインが一体化している。
- **TypeScript化とPython化の並行進化**: Web開発・自動化の世界ではTypeScript/Node.jsが主流だが、MLエンジニアのPython需要に応えてcrawlee-pythonが登場。同一のAPIコンセプトを両言語で提供することで、言語を問わずCrawleeのエコシステムが活用できるようになっている。
- **ブロック回避技術の標準化**: IPブロック・CAPTCHAへの対策がライブラリレベルで標準提供されるようになった。プロキシローテーション・セッション管理・ブラウザ指紋偽装が設定数行で使えるため、スクレイピングの安定性が向上し、MLデータ収集の自動化が実用的なレベルに達している。
