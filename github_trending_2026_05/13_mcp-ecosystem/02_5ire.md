## 概要

5ireは、主要LLMプロバイダー（OpenAI・Anthropic・Gemini・Groq・Ollama等）をサポートするクロスプラットフォームのデスクトップAIアシスタントで、MCPクライアントとしての機能も持つ。ローカルナレッジベース・MCPサーバーツール・マルチモデル対応を統合した「オールインワン」のAIデスクトップ環境を提供する。

Claude Desktopに近いポジションだが、5ireはマルチLLMに対応しておりGPT-4o・Claude・Gemini・ローカルOllamaモデルをシームレスに切り替えられる点が特徴。MCPサーバーの管理UIが内蔵されており、GUIでMCPサーバーの追加・設定・オン/オフが可能。Electron製のデスクトップアプリとしてmacOS・Windows・Linuxで動作する。

---

## 主な機能

| 機能 | 詳細 |
|------|------|
| **マルチLLM対応** | OpenAI・Anthropic・Gemini・Groq・Ollama・Azure OpenAIを切り替え可能 |
| **MCPクライアント** | MCPサーバーをGUI管理・ツール実行が可能 |
| **ローカルナレッジベース** | ファイルをローカルでベクトル化してRAGとして利用 |
| **クロスプラットフォーム** | macOS・Windows・Linux対応（Electron製） |
| **会話履歴管理** | チャット履歴をローカルに保存・検索可能 |
| **カスタムシステムプロンプト** | ペルソナ・用途ごとのプロンプトを設定 |
| **ショートカットキー** | グローバルショートカットでどの画面からでも即起動 |
| **プロバイダー料金比較** | 各モデルのコストをUIで確認しながら選択 |

---

## あるとないとの違い

| 観点 | Claude Desktop単体 | 5ire |
|------|-------------------|------|
| 対応LLM | Claudeのみ | OpenAI・Gemini・Ollama等も対応 |
| MCPサーバー管理 | JSONファイル編集が必要 | GUIで管理・設定 |
| ローカルモデル | Ollamaは非対応 | Ollamaをネイティブサポート |
| ナレッジベース | なし | ローカルファイルをRAGとして利用可能 |
| コスト比較 | なし | モデルごとの料金をUIで表示 |
| カスタマイズ | 設定項目が少ない | システムプロンプト・動作を細かく設定 |

## 環境構築方法

### インストール

```bash
# GitHubリリースページからダウンロード
# https://github.com/nanbingxyz/5ire/releases

# macOS (Apple Silicon)
# 5ire-macos-arm64.dmg をダウンロードしてインストール

# Windows
# 5ire-windows-x64.exe をダウンロードして実行

# Linux (AppImage)
chmod +x 5ire-linux-x86_64.AppImage
./5ire-linux-x86_64.AppImage
```

### ソースからビルド

```bash
# Node.js 18以上が必要
git clone https://github.com/nanbingxyz/5ire.git
cd 5ire

npm install

# 開発モードで実行
npm run dev

# 本番ビルド
npm run build
# → dist/ にバイナリが生成される
```

### 初期設定（APIキーの登録）

```
# 5ire起動後の設定手順:
1. 設定アイコン → 「Providers」タブ
2. 使用するプロバイダーを選択
3. APIキーを入力して保存

# 対応プロバイダーと設定キー:
OpenAI:      OPENAI_API_KEY
Anthropic:   ANTHROPIC_API_KEY
Gemini:      GOOGLE_AI_API_KEY
Groq:        GROQ_API_KEY
Azure:       AZURE_OPENAI_API_KEY + エンドポイント
Ollama:      URL設定のみ（http://localhost:11434）
```

### MCPサーバーの追加（GUI経由）

```
# 5ire での MCPサーバー設定手順:
1. 設定 → 「MCP Servers」タブ
2. 「+ Add Server」ボタン
3. 以下を入力:
   - 名前: GitHub
   - コマンド: npx
   - 引数: -y @modelcontextprotocol/server-github
   - 環境変数: GITHUB_PERSONAL_ACCESS_TOKEN = ghp_...
4. 「Save」して有効化

# チャット画面でツールが使えるようになる
# 入力欄横の「ツール」アイコンで利用可能なMCPツールを確認
```

## セキュリティ観点

### APIキーの保管

```bash
# 5ire はAPIキーをOSのキーチェーン（macOS Keychain / Windows Credential Store）に保存
# ハードコーディングや平文ファイルへの保存はされない

# ただし以下に注意:
# - バックアップを取る場合、キーチェーンも含めてエクスポートされるか確認
# - 共用PCへの5ireインストールは避ける（他のユーザーがAPIキーにアクセス可能な場合）
```

### MCPサーバーのサンドボックス化

```bash
# MCPサーバーはnpxでインターネットから取得・実行されるため
# 信頼できるパッケージのみ使用する

# パッケージの事前確認
npm info @modelcontextprotocol/server-github
# → パッケージ作者・バージョン・ダウンロード数を確認

# ファイルシステムMCPは最小限のディレクトリのみ許可
# × /home/user（すべてのファイルにアクセス可能）
# ○ /home/user/projects/specific-project（特定プロジェクトのみ）
```

### ローカルナレッジベースの保護
- ナレッジベースのベクトルDBはローカルに保存されるが、ファイルの暗号化は手動で行う必要がある
- 機密性の高いドキュメントは5ire終了時に都度削除する運用を検討する
- Ollamaでローカルモデルを使う場合でも、MCPサーバーが外部APIを呼び出す可能性があるため注意する

```
# 5ire の設定と日常ワークフロー

## 設定済みプロバイダー:
```

```python
# 5ire × MCPサーバーを使った実際の作業例:

# 小林: 「~/projects/data-pipeline/src/processor.py を読んで
#        パフォーマンス改善の提案をして。
#        改善版を processor_v2.py として保存して」

# 5ire (Claude Sonnet)の動作:
# 1. [filesystem:read_file] processor.py を読み込み
# 2. コードを分析して改善提案を生成
# 3. [filesystem:write_file] processor_v2.py を保存

# 改善前のコード（仮）
def process_items(items: list) -> list:
    results = []
    for item in items:
        # N+1的な処理
        db_result = fetch_from_db(item["id"])  # 1件ずつDBアクセス
        results.append(transform(item, db_result))
    return results

# 5ire が提案・生成した改善版
async def process_items_v2(items: list) -> list:
    # IDをまとめてバッチフェッチ
    ids = [item["id"] for item in items]
    db_results = await fetch_from_db_batch(ids)  # 1回のDBアクセス
    db_map = {r["id"]: r for r in db_results}

    return [transform(item, db_map[item["id"]]) for item in items]
# 処理速度: 1件ずつ → バッチ処理で約10倍高速化
```

**導入前後の変化:**
- 導入前: ChatGPT・Claude・ブラウザタブを行き来 → コンテキストの共有ができず、コードをコピペして貼り付ける作業が毎回必要
- 導入後: 5ire一つで完結 → MCPツールでファイルを直接参照・保存、モデルをワンクリックで切り替え、ローカルドキュメントもRAGとして利用
