## 概要

AIエージェント開発のためのオールインワンツールキット。CLIエージェント・統一LLM API・TUI/WebUIライブラリ・Slackボット・vLLMポッドを単一フレームワークで提供する。

Claude Code・Codex・Gemini CLI等の「コーディングエージェント」と異なり、**任意ドメインのエージェントを素早く構築・デプロイするための基盤**として設計されている。

---

## 主要コンポーネント

| コンポーネント | 役割 |
|--------------|------|
| **coding agent CLI** | Claude Code系のコーディングエージェントCLI |
| **unified LLM API** | Claude/GPT/Gemini等を単一APIで呼び出す |
| **TUI library** | ターミナルUIコンポーネントライブラリ |
| **Web UI library** | Webベースのエージェントフロントエンド |
| **Slack bot** | SlackからエージェントをトリガーするBot |
| **vLLM pods** | ローカルLLMのPodデプロイ管理 |

---

## あるとないとの違い

| 観点 | 個別ツールを組み合わせ | pi |
|------|---------------------|-----|
| LLM切り替え | プロバイダーごとにコード変更 | 設定1行で切り替え |
| UI構築 | Reactアプリを別途作る | TUI/WebUI付属 |
| Slackデプロイ | Bolt等の設定が必要 | Slackボットが内蔵 |
| ローカルLLM | vLLM設定が複雑 | vLLMポッド管理が統合 |

## 環境構築方法

```bash
npm install -g @earendil/pi
# または
pip install earendil-pi

# 初期化
pi init my-agent
cd my-agent

# 設定
# pi.config.ts
export default {
  llm: {
    provider: "anthropic",  // or "openai" | "gemini" | "local"
    model: "claude-opus-4-7",
  },
  tools: ["bash", "read", "write", "web_search"],
}

# エージェント起動
pi run
```

### Slackボットとして動かす

```bash
pi deploy slack \
  --token $SLACK_BOT_TOKEN \
  --app-token $SLACK_APP_TOKEN
# → SlackでメンションするとエージェントがDMで応答
```

### vLLMポッドでローカルLLM

```bash
pi pod start \
  --model meta-llama/Llama-3-70B-Instruct \
  --gpu 2  # GPU数
# → ローカルエンドポイントが立ち上がり、unified APIから呼べる
```

## ベストプラクティス

```typescript
// カスタムエージェントの実装例
import { Agent, tool } from "@earendil/pi";

const myAgent = new Agent({
  system: "あなたは社内データ分析専門のエージェントです",
  tools: [
    tool.bash(),
    tool.read(),
    // カスタムツール
    tool.custom({
      name: "query_db",
      description: "社内DBにSQLを実行する",
      schema: { sql: "string" },
      handler: async ({ sql }) => {
        return await db.query(sql);
      },
    }),
  ],
});

// TUIで起動
await myAgent.runTUI();
// WebUIで起動
await myAgent.runWeb({ port: 3000 });
// Slackで起動
await myAgent.runSlack({ token: process.env.SLACK_BOT_TOKEN });
```
