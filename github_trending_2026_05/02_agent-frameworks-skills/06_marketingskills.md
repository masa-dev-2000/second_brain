## 概要

CRO・コピーライティング・SEO・グロースエンジニアリング・アナリティクスなどマーケティング全域をカバーする50以上のAIエージェントスキル集。Claude Code等のAIコーディングエージェントにマーケティングの専門知識を注入し、技術的なマーケタスクを自動化する。

各スキルは相互参照・連携しており、「product-marketing」という基盤スキルを中心に体系的な知識システムを形成している。

---

## 収録スキルカテゴリ（50以上）

| カテゴリ | 主なスキル |
|---------|-----------|
| **CRO（コンバージョン最適化）** | LP最適化、フォーム改善、ペイウォール設計、ABテスト設計 |
| **コピーライティング** | LPコピー、メールコピー、SNS投稿、プレスリリース |
| **SEO** | 技術SEO監査、コンテンツ最適化、構造化データ、内部リンク |
| **グロース** | リファラルプログラム、無料ツール戦略、パートナーシップ |
| **アナリティクス** | GA4セットアップ、ABテスト計測、ファネル分析 |
| **セールス支援** | ピッチデッキ、提案書、異議対応テンプレート |

## あるとないとの違い

| 依頼内容 | スキルなし | スキルあり |
|---------|-----------|-----------|
| 「LPのCVRを上げて」 | 「CTAボタンの色を変えましょう」（一般論） | ファネル分析→ヒートマップ仮説→ABテスト設計→実装→計測設定まで一連のワークフロー |
| 「SEOを改善して」 | 「キーワードを増やしましょう」 | 技術SEO監査→Core Web Vitals→構造化データ→内部リンク最適化→検索意図分析 |
| 「メールを書いて」 | 汎用的なメール文面 | コピーライティングの原則（AIDA・PAS）に基づいた転換率最大化の文面 |

## 環境構築方法

### 前提条件
- Claude Code / Cursor / GitHub Copilot CLI のいずれか
- Googleアナリティクス・GTMのアクセス権（アナリティクス系スキル使用時）

### インストール手順
```bash
# Claude Codeプラグインとしてインストール
/plugin install marketing-skills@claude-plugins-official

# または手動でクローン
git clone https://github.com/coreyhaines31/marketingskills
cd marketingskills

# プロジェクトルートにコアスキルを配置
cp skills/product-marketing.md CLAUDE.md  # 基盤スキル
cat skills/cro.md >> CLAUDE.md            # CROスキルを追加
cat skills/seo.md >> CLAUDE.md            # SEOスキルを追加
```

### 最小構成（入門向け）
```bash
# まず基盤スキルだけ入れてみる
cp skills/product-marketing.md .claude/marketing.md
```

### 動作確認
```bash
claude "このLPのコンバージョン率を改善したい"
# → "現在のCVR・トラフィックソース・主要CTAを教えてください" と聞いてくれれば成功
```

## ベストプラクティス

1. **プロダクトコンテキストを先に共有する:**
```markdown
# CLAUDE.mdにプロダクト情報を記載
## プロダクト概要
- 名前: TaskFlow
- ターゲット: 中小企業のプロジェクトマネージャー
- 価格: $29/月（Free、Pro、Enterprise）
- 主なUSP: Jira比80%シンプル・Notion比リアルタイム性
- 現在のCVR: 2.1%（業界平均3.5%）
```

2. **段階的にスキルを追加する:**
```
Week 1: product-marketing.md（基盤）
Week 2: cro.md（CVR改善が最優先課題）
Week 3: seo.md（オーガニック流入を増やしたい）
Week 4: analytics.md（計測体制を整える）
```

3. **グロース実験のログを取る:**
```bash
# 実施した施策の記録
claude "今週実施したABテストの結果をまとめて、
       次のイテレーションの仮説を立てて"
```

4. **コピーのA/Bテストを体系的に管理:**
```
"このCTAの文言を5パターン生成して。
 各パターンに使用したコピーライティングの原則も記載して"
→ A: 利益訴求型（FOMO活用）
→ B: 問題解決型
→ C: 社会的証明型
...
```

## セキュリティ観点

### ユーザーデータの取り扱い
- ABテスト・アナリティクス設定でユーザーの行動データを扱う場合、プライバシーポリシーへの記載が必要
- EU向けサービスはGDPR、日本向けは個人情報保護法への準拠を確認

### 広告・コピーの法的注意
```
# スキルが生成するコピーには以下を人間が確認する：
- 誇大広告的な表現がないか
- 競合他社との比較表現は事実に基づいているか
- ステルスマーケティング規制への準拠
```
