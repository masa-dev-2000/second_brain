## トレンドから読み解く2026年5月のAI開発動向

### 1. MCPエコシステムの成熟
トップ10のうち4つがMCPサーバー関連。AIコーディングツールへのコンテキスト提供が標準化されつつある。

### 2. 「作る側」から「使う側」へのシフト
LLM自体の開発よりも、LLMを使いこなすためのワークフロー・評価・コスト最適化への関心が高まっている。

### 3. セルフホストの加速
WhatsApp Business API・SAP・Gamma・Plex等の商用SaaSをOSSで自己ホストする動きが各カテゴリで見られる。

### 4. エージェントの実用化
「エージェントとは何か」の議論から「エージェントをどう設計・評価・本番化するか」への移行が明確。

### 5. AIエンジニアリング教育の本格化
Anthropic等のAI企業が体系的なカリキュラムをOSSで公開。「AI使える人材」の育成が産業的課題に。

## 各ファイルの構成

全ファイルは以下の共通フォーマットで記述されている:

1. **基本情報** — リポジトリURL・スター・ライセンス等
2. **概要** — 何を解決するツールか
3. **主な機能** — 機能一覧表
4. **あるとないとの違い** — Before/After比較表
5. **環境構築方法** — セットアップ手順・動作確認
6. **ベストプラクティス** — 実践的な使い方のコード例
7. **セキュリティ観点** — リスクと対策
8. **ペルソナ設定と使い方** — 具体的な人物設定による使用シナリオ
9. **周辺情報** — 類似ツールとの比較
10. **参考リンク** — 公式リポジトリ等
