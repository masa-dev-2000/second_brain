# 08_rag-second-brain

## フォルダの概要

RAG（Retrieval-Augmented Generation）とセカンドブレイン構築に関するOSSプロジェクトをまとめたカテゴリ。個人の知識ベースをAIで強化するKhojや、グラフ構造を活用した高精度検索のLightRAG・GraphRAGなど、「自分専用のAI知識アシスタント」を構築するためのツール群を収録している。LLMの弱点である知識の陳腐化・ハルシネーションを検索ベースで補完するアプローチとして、2025〜2026年にかけてエンタープライズ・個人利用の両面で急速に普及している。

## カテゴリの傾向

- **グラフRAGの台頭**: 従来のベクトル検索だけでなく、エンティティ間の関係を知識グラフとして表現することで、複雑なマルチホップ質問への回答精度が大幅に向上している。MicrosoftのGraphRAGがその先駆けとなり、LightRAGがさらにローカルかつ軽量な実装を提供している。
- **ローカルファーストの強化**: セキュリティ・プライバシー要件の高まりから、クラウドに依存しないローカルLLM（Ollama等）とRAGを組み合わせるソリューションが増加。企業内の機密ドキュメントや個人の日記・メモをAIに学習させる需要が拡大している。
- **RAGの評価・品質管理の重要性**: RAGシステムの普及に伴い、検索の関連性・回答の忠実度・精度を自動評価するフレームワーク（RAGAS・MLflow等）の需要が高まっており、プロダクション運用のベストプラクティスが急速に確立されつつある。
