# 09_image-generation

## フォルダの概要

オープンソースの画像生成AIツールとマルチモーダル創作支援ツールをまとめたカテゴリ。Stable DiffusionやFLUXなどの拡散モデルをノードベースのパイプラインで操作するComfyUIを筆頭に、テキスト指示で創作作業を支援するjaazを収録している。商用クラウドサービス（Adobe Firefly・Canva・Midjourney等）への対抗として、プライバシーを守りながらローカルで高品質な画像生成・デザイン制作を行うためのOSSエコシステムが急速に成熟している。

## カテゴリの傾向

- **ノードベースUIが業界標準に**: ComfyUIのノード＆ワイヤー方式が画像生成ワークフローの標準として確立。処理の各ステップを可視化・交換できる柔軟性により、ControlNet・LoRA・IPAdapterを組み合わせた複雑なプロフェッショナルワークフローが誰でも構築できるようになった。
- **テキスト指示ベースのクリエイティブツールの台頭**: 専門的なプロンプトエンジニアリングの知識なしに、自然言語の指示だけで画像生成・デザイン制作が行えるjaazのようなツールが登場。クリエイター以外の一般ビジネスユーザーも画像AI生成を活用できる門戸が広がっている。
- **ローカル＆プライバシーファーストの重要性**: 企業の機密素材や個人の未発表作品を外部クラウドに送信せずに処理できるローカル実行型ツールへの需要が拡大。ComfyUIとOllamaを組み合わせることで完全オフラインの画像生成パイプラインが実現できるようになっている。
