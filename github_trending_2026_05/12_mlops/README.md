## カテゴリの傾向

- **MLOpsからLLMOpsへの拡張**: 従来の機械学習実験管理ツールがLLMアプリケーション（RAG・エージェント・プロンプトエンジニアリング）のオブザーバビリティ・評価機能を大幅に強化している。MLflowのLLMトレーシング・プロンプト管理機能はその代表例で、AIエンジニアリング全体をカバーするプラットフォームへと進化している。
- **LLM評価の自動化が標準的に**: LLMの応答品質（忠実度・関連性・正確性）を人手ではなくLLM自身で評価する「LLM-as-a-Judge」アプローチが普及しつつある。MLflowのmlflow.evaluate()はOpenAIやAnthropicのモデルを使った自動評価パイプラインを提供しており、継続的なクオリティ管理が自動化されている。
- **再現性とガバナンスへの注目**: 生成AIシステムが本番運用されるにつれ、「どのモデル・プロンプト・データで生成したか」の記録と再現性が法令対応・品質保証の観点で重要になっている。MLflowのモデルレジストリと実験追跡機能がこのガバナンス要件に対応するインフラとして採用が拡大している。
