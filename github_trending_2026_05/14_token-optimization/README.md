# トークン最適化ツール

LLM APIのコストとトークン使用量を削減するためのOSSツールおよびプロバイダー機能。

---

## 収録ツール

| # | ツール | カテゴリ | 特徴 |
|---|--------|---------|------|
| 01 | [Langfuse](./01_langfuse.md) | LLM可観測性 | トークン・コストの可視化とトレーシング |
| 02 | [LiteLLM](./02_litellm.md) | LLMゲートウェイ | 100+ LLM統一API・チーム別予算管理 |
| 03 | [OpenLit](./03_openlit.md) | OpenTelemetryモニタリング | GPU監視を含むLLMコスト全体管理 |
| 04 | [LLMLingua](./04_llmlingua.md) | プロンプト圧縮 | Microsoftの3〜20倍圧縮ライブラリ |
| 05 | [GPTCache](./05_gptcache.md) | セマンティックキャッシュ | 意味的類似クエリのキャッシュで60〜80%削減 |
| 06 | [プロバイダー機能](./06_provider-features.md) | Anthropic/OpenAI公式 | プロンプトキャッシング・Batch API |

---

## 最適化戦略の選び方

```
コストを「見える化」したい
  → Langfuse (#01) または OpenLit (#03)

チーム全体のコストを管理・制限したい
  → LiteLLM (#02)

同じプロンプトを繰り返し送る（RAG・システムプロンプト）
  → Anthropic プロンプトキャッシング (#06)

同じ質問が繰り返されるFAQ・サポートボット
  → GPTCache (#05)

RAGのコンテキストが長大でコストが高い
  → LLMLingua (#04)

リアルタイム不要な大量バッチ処理
  → Anthropic Batch API (#06)
```

---

## コスト削減効果の比較

| 手法 | 削減率 | 導入コスト |
|------|--------|----------|
| Anthropicプロンプトキャッシング | 30〜70% | 低（数行） |
| Batch API | 50% | 低〜中 |
| GPTCacheセマンティックキャッシュ | 40〜80% | 中 |
| LLMLinguaプロンプト圧縮 | 30〜70% | 中〜高 |
| モデルダウングレード（Opus→Haiku） | 95% | 中（精度評価が必要） |
